Ctrl + C - копировать выделенное
Ctrl + V - вставить выделенное
Ctrl + X - копировать и удалить выделенное
Ctrl + A - выделить все
Ctrl + F - поиск введенного
Ctrl + левая кнопка мыши(ЛКМ) - выделение по очереди
стрелочки - передвижение курсора
Ctrl + стрелочки - передвижение курсора по словам
Ctrl + Shift + стрелочки - выделение по словам
Shift + стрелочки - выделение по буквам
Shift + ЛКМ - выделение всего от старой позиции курсора до нового
